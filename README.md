# Spall Native

A fork of Spall Native with additional fixes and improvements.

## Description

Spall Native is a desktop application for viewing large program traces generated by the Spall profiler library

## Changes from Upstream

- Fixed the build on windows and linux
- Migrated most things to odin's new core:os
- Improved the color generation for the flame graph

## Getting Started

### Dependencies

- Odin compiler
- Odin standard packages (core, base, etc.)

### Build

Windows:
```
./build.bat release
```

Linux, macOS:
```
./build.sh release
```

The binary will be placed in the `bin` directory.  
Remove the `release` flag to build the debug version.

### Notes

- Tested on Windows and Linux only.
